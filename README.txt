Prophesee Starter Kit - STM32F7 - Demo Application

Overview
This demo showcases how to use the Prophesee GenX320 Event-Based Vision Sensor with the STM32 microcontroller kit.
It demonstrates the basic workflow for capturing, processing, and visualizing event-based data.

Features:
* Sensor initialization and event streaming using CPI interface
* Power modes
* Sensor's internal status in Low Power Monitor mode
* Smart wake-up feature using RISC-V
* LED tracking using RISC-V

Requirements:
Hardware:
* Prophesee Starter Kit STM32F7 (GenX320)
* STM32F746G Discovery kit
* USB cable for data transfer
* Host PC for visualization

Software:
* STM32CubeIDE
* Demo application source code developped using the following libraries:
  * TouchGFX 4.22.0
  * STM32CubeMX 6.8.0
